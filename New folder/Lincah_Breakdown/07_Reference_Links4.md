| Cara mengintegrasikan open API | Untuk mengintegrasikan open API hanya bisa dilakukan jika diajukan ke tim IT. Syaratnya yaitu volume pengiriman kurang lebih 1000/bulan. Namun, ada syarat yang harus terpenuhi yaitu volume pengiriman kurang lebih 1000/bulan. Jika kaka sudah memenuhi persyaratan tersebut, akan kami bantu ajukan ke tim IT kami. | Perhitungan Nilai Barang COD | Nilai COD = harga barang + ongkir + fee COD. Fee COD = (harga barang + ongkir) * 3,33%. Tidak ada biaya admin jika metode pembayaran Transfer/Non COD. |
| Withdraw dan Top Up | Kode WD: WDXXX untuk withdraw. Kode BLN: BLNXXX untuk top up saldo biasanya menggunakan transfer bank. Jika seller mengeluhkan sudah top up namun saldo belum bertambah, mintakan no transaksi yang diawali BLNFU ke Finance melalui grup LiveChat X Finance X AMedukasi. Jika WD gagal atau hold, teruskan ke finance. Hold WD beberapa seller diterapkan untuk minim fraud/blasting. Estimasi pengecekan 3x24 sampai 4x24 jam tergantung kasus. |
