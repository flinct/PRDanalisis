## Bab 3- Kamus Logistik

| Nama | Pengertian |
| :---- | :---- |
| AWB (Air Waybill) / Resi | Nomor identitas unik untuk setiap paket. Ibarat KTP-nya paket. Digunakan untuk melacak posisi paket.  |
| Shipper | Pengirim paket (biasanya penjual online) |
| Platform | Peran kita sebagai penyedia jasa layanan logistik berbasis digital |
| Consignee | Penerima paket (pembeli) |
| 3PL (Third-Party Logistics) | Perusahaan kurir seperti JNE,SAP,ID EXPRESS, yang menyediakan jasa logistik untuk pihak lain |
| First Mile | Proses penjemputan paket dari lokasi pengirim ke Hub pertama |
| Mid Mile / Line Haul | Proses pengiriman paket antar Hub/gudang utama (misalnya, dari Jakarta ke Surabaya).  |
| Last Mile | Proses pengiriman paket dari Hub tujuan ke alamat akhir penerima. Ini adalah tugas utama kurir lapangan kita |
| Hub / Sorting Center | Gudang pusat tempat paket dikumpulkan, disortir, dan didistribusikan |
| COD (Cash on Delivery) | Bayar di Tempat. Pembeli membayar tunai saat paket diterima |
| Non-COD | Paket yang sudah dibayar lunas secara online |
| POD (Proof of Delivery) | Bukti bahwa paket telah berhasil diantar. Bisa berupa foto, tanda tangan, atau update status digital |
| Sorting (Sortir) | Proses memilah-milah paket berdasarkan kode pos atau area tujuan pengiriman |
| Scan In / Scan Out | Tindakan memindai barcode AWB menggunakan alat scanner atau aplikasi untuk memperbarui status paket di sistem |
| Failed Delivery / Undel | Pengiriman gagal. Bisa karena alamat tidak ditemukan, penerima tidak di tempat, atau menolak paket |
| RTS (Return to Shipper) | Proses pengembalian paket ke pengirim karena gagal kirim setelah beberapa kali percobaan |
| Reconciliation (Rekonsiliasi) | Proses pencocokan data. Paling sering digunakan untuk memastikan jumlah uang COD yang diterima kurir sesuai dengan data paket yang berhasil diantar |
| Remittance (Remitansi) | Proses transfer dana (biasanya dana COD) dari perusahaan logistik ke pihak lain |
| INCOMPLETE CONSIGNEE ADDRESS  | Alamat penerima (consignee) yang dicantumkan tidak lengkap. Misalnya, tidak ada nomor rumah, RT/RW, atau nama jalan yang tidak jelas |
| CONSIGNEE REFUSE TO PAY COD SHIPMENT/SHIPMENT FEE | Penerima menolak untuk membayar total tagihan COD (harga barang \+ ongkos kirim) saat kurir tiba di lokasi |
| DELIVERY PROBLEM | Ini adalah status umum yang menandakan adanya kendala tak terduga selama proses pengantaran oleh kurir |
| NOBODY AT HOME / OFFICE TO RECEIVE SHIPMENT | Kurir telah tiba di alamat yang benar, tetapi tidak ada seorang pun di lokasi untuk menerima dan membayar paket |
| SHIPMENT PICKED UP BY CONSIGNEE AS REQUESTED BY SHIPPER/CONSIGNEE | Paket telah berhasil diambil sendiri oleh penerima di kantor cabang, gudang, atau drop point milik platform logistik. Pengambilan ini terjadi atas permintaan dari penerima atau penjual |
| COMPLETE ADDRESS, BUT CONSIGNEE UNKNOWN | Alamat yang diberikan sudah benar dan lengkap, namun orang yang tinggal atau bekerja di alamat tersebut tidak mengenal nama penerima yang tertera di paket |
| RECIPIENTS REFUSED TO RECEIVE COD SHIPMENT (NOT ORDER) | Penerima menolak paket dengan alasan spesifik: merasa tidak pernah memesan barang tersebut |
| SHIPMENT PROBLEM  | Sama seperti "DELIVERY PROBLEM", ini adalah status umum, tetapi biasanya merujuk pada masalah yang terkait dengan kondisi fisik paket itu sendiri, bukan proses pengantarannya |
| HOME/OFFICE ADDRESS ALREADY MATCH,BUT CONSIGNEE MOVED | Alamatnya benar, tetapi penerima yang dituju sudah pindah dari alamat tersebut |
| SHIPMENT BEING HELD DUE TO DID NOT PASS X-RAY CHECK \-DOCUMENTS ARE NOT COMPLETE | Paket ditahan di fasilitas logistik (biasanya di bandara atau pusat sortir utama) karena tidak lolos pemeriksaan X-Ray atau dokumen pendukungnya tidak lengkap. |
| SHIPMENT BEING HELD AS SHIPPERS REQUEST | Pengiriman paket dihentikan atau ditunda sementara atas permintaan langsung dari penjual (shipper) |
| CLOSED / NOT AVAILABLE | Ini adalah status pembaruan pengiriman yang berarti kurir sudah tiba di alamat tujuan, tetapi lokasi tersebut (kantor, toko, atau rumah) dalam keadaan tutup, atau tidak ada orang yang bisa dihubungi untuk menerima paket |
| SLA (Service Level Agreement) | SLA adalah perjanjian atau standar waktu layanan yang dijanjikan oleh platform logistik kepada pengirim (penjual). Misalnya, layanan "Same Day" memiliki SLA 1 hari, atau layanan "Reguler" untuk Jakarta-Bandung memiliki SLA 1-2 hari |
| First Mile | Ini adalah tahap awal dari rantai pasok logistik, yaitu proses penjemputan (pickup) paket dari lokasi penjual/pengirim untuk dibawa ke pusat sortir (Hub) pertama |
| Ticketing | Sistem ticketing adalah sebuah platform atau sistem yang digunakan untuk mencatat, melacak, dan mengelola keluhan atau permintaan dari pelanggan (penjual atau pembeli). Setiap masalah (misalnya, paket hilang, pengiriman terlambat, permintaan informasi) akan dibuatkan "tiket" dengan nomor unik |
| Hub | Hub adalah pusat transit atau gudang sentral di mana paket-paket dari berbagai daerah dikumpulkan, disortir berdasarkan kota atau area tujuan, lalu didistribusikan kembali. Ada Hub utama (biasanya di kota besar) dan Hub cabang (di kota/kabupaten yang lebih kecil) |
| Line Haul | Ini adalah proses transportasi paket dalam jumlah besar antar Hub utama. Biasanya menggunakan armada besar seperti truk tronton atau pesawat kargo untuk perjalanan jarak jauh (antar kota atau antar pulau) |
| Sorter | Sorter bisa merujuk pada mesin penyortir otomatis atau petugas (manusia) yang bertugas memisahkan paket-paket di dalam Hub berdasarkan kode pos atau area tujuan pengiriman |
| Midmile | Ini adalah tahap tengah dalam proses logistik, yang mencakup semua aktivitas setelah paket meninggalkan Hub asal hingga tiba di Hub tujuan yang terdekat dengan alamat penerima. Proses Line Haul adalah bagian utama dari Midmile |
| Last Mile | Ini adalah tahap akhir dan paling krusial dari proses pengiriman, yaitu perjalanan paket dari Hub tujuan akhir ke alamat penerima. Proses ini dilakukan oleh kurir |
| Criss Cross | Ini adalah istilah untuk kesalahan rute pengiriman, di mana paket terkirim ke Hub atau kota yang salah (salah sortir). Contoh: paket untuk penerima di Jakarta, tetapi terkirim ke Hub di Surabaya |
| Lead Time | Lead Time adalah total waktu yang dibutuhkan sejak pesanan dibuat oleh pelanggan hingga paket diterima. Ini mencakup waktu proses oleh penjual (untuk menyiapkan barang) dan total waktu pengiriman oleh logistik (First, Mid, dan Last Mile) |
| Over SLA | Pengiriman paket melebihi batas waktu yang dijanjikan dalam Service Level Agreement. Misalnya, layanan yang dijanjikan 1-2 hari, tetapi paket baru sampai di hari ke-3 |
| Meet SLA | Pengiriman paket berhasil diselesaikan sesuai atau lebih cepat dari batas waktu yang dijanjikan dalam Service Level Agreement |
| DO Kembali | "DO" adalah singkatan dari Delivery Order (Surat Jalan Pengiriman). "DO Kembali" berarti surat jalan tersebut diproses untuk pengembalian. Dalam praktiknya, ini merujuk pada proses RTO (Return to Origin), di mana paket dikembalikan ke alamat pengirim. |
| Attempt | proses pengantaran ke penerima oleh kurir sampai ke titik alamat penerima, attempt juga terdiri dari attempt pertama ( Percobaan pengantaran pertama ), Atttempt kedua ( percobaan pengantaran kedua ), Attempt ketiga ( percobaan pengantaran ketiga ) dan seterusnya sesuai regulasi yang dipunya oleh pihak 3PL |
