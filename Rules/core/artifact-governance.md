# Artifact Governance

The project profile defines directories, naming, templates, retention, owners,
and versioning. Rules: artifacts that influence a material decision must be
findable, have a stable reference, identify version/status, and preserve a concise
change history. Keep generated outputs separate from authored sources and document
their generator/source contract.

A project profile MAY require that every substantive update to a permanent
artifact raise its version and append a change summary. When it does, that
requirement is non-bypassable.

Session summaries should record objective, decisions, material evidence, changed
artifacts, open items, and next action. Full transcripts are optional by default
and must follow the project's privacy and retention policy.

A project profile MAY require that every session keep a live summary file with a
complete, verbatim, chronological transcript of all turns. When it does, that
requirement (including no gaps, no truncation, and redaction-only edits) is
non-bypassable.
