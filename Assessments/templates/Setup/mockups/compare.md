# Setup Dashboard Mockup Comparison

## Variant A — Control Center
**Path:** `Assessments/templates/Setup/mockups/01-control-center/index.html`

Cocok kalau dashboard lebih sering dipakai untuk:
- audit setup
- cek policy aktif
- lihat roster agent
- validasi freeze/gate/rule status

## Variant B — Workflow Builder
**Path:** `Assessments/templates/Setup/mockups/02-workflow-builder/index.html`

Cocok kalau dashboard lebih sering dipakai untuk:
- atur lane full/fast
- lihat urutan step agent
- edit routing
- pahami gate dan freeze secara visual

## Rekomendasi saya
Kalau ini untuk tahap awal, **pakai hybrid dengan baseline Variant A** lalu ambil **panel workflow builder** dari Variant B.

Artinya:
- sidebar + summary + tabs dari Variant A
- sequence builder / inspector workflow dari Variant B

Jadi hasil akhirnya bukan sekadar settings statis, tapi tetap punya visual orchestration yang kuat.
