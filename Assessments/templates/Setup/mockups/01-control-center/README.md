## Variant: Control Center

### Design stance
Dashboard bergaya command center dengan left navigation stabil dan panel konten besar di kanan.

### Key choices
- Layout: sidebar kiri + content area kanan
- Emphasis: policy-first, cocok untuk admin setup
- Interaction: klik nav untuk pindah Rule / Agent / Workflow Agent; klik roster agent untuk lihat detail

### Trade-offs
- Strong at: cepat scan state sistem, cocok untuk setup canonical dan governance
- Weak at: kurang cocok untuk editing workflow panjang yang butuh canvas visual lebih dalam

### Best for
- User yang ingin melihat status setup secara cepat
- Admin yang lebih sering audit / validate daripada drag-drop workflow
