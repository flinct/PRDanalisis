# Strategy Library — Market, Competitor, Positioning

Folder ini menyimpan analisa **market/competitor/positioning strategis** untuk SatuInbox — beda scope dari `Assessments/reference/` (yang fokus PRD cross-analysis internal produk).

## Isi

- `satuinbox-client-profiles-research.md` — profil bisnis 3 client SatuInbox (BantuSaku/fintech OJK, Song Fa/F&B chain lintas negara, Farmacare/software apotek B2B) dari riset web publik. Farmacare partial (extraction diblokir, data dari search snippet saja).
- `satuinbox-product-strategy-synthesis-2026.md` — **sintesis terbaru (2026-08-26)**: target pasar, fitur cocok per segmen, flow eksisting end-to-end, perbaikan existing (bug/PRD-risk/test-gap dipisah), fitur baru (scoring 7-kriteria), strategi pemasaran. Merevisi ICP dari "logistics-only" ke "high-volume customer operations" berdasar client matrix terbaru (SAP, Lion Parcel, Bantu Saku, Farmacare, Song Fa). Baca ini dulu sebelum dokumen di bawah — yang di bawah adalah source material historis.
- `satuinbox-competitive-analysis.md` — feature matrix + pricing 7 kompetitor global SaaS (Qontak, Respond.io, WATI, SleekFlow, Freshchat, Zendesk, Chatwoot).
- `satuinbox-usp-innovation-analysis.md` — USP SatuInbox (Proven Operation Engine lintas vertical, hybrid WA — **revisi 2026-08-26: SaaS-only, klaim self-hosted dibuang**) + gap inovasi + roadmap + positioning/pitch/tagline.
- `satuinbox-logistics-vertical-positioning.md` — kompetitor lokal ID (Barantum, Qiscus, Cekat.AI, Halo AI) + vertical logistik + customer behavior data + kompetitor global post-purchase tracking (AfterShip, Narvar, Parcel Perform, Yalo).
- `satuinbox-competitor-deep-dive-round3.md` — deep-dive fitur/pricing/client per platform (Qontak, Qiscus, Barantum, Cekat.AI, SleekFlow, Chatwoot) + 3 kandidat baru (Halo AI, Kata.ai, TapTalk OneTalk).
