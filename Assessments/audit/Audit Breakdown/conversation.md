# Features

Conversations

---

# Purpose

Conversations is the main feature in the Conversations module, used by agents to receive, read, reply to, and manage customer conversations from various communication channels. Such as:

*   Telegram
*   WhatsApp API
*   Email
*   Facebook
*   Facebook Messenger
*   Instagram
*   Instagram Comments
*   WhatsApp Web
*   WhatsApp Web Groups
*   Widget

This feature is the center of agent activity when using SatuInbox.

---

# Business Purpose

*   Manage customer communications.
*   Make it easier for agents to respond to customers.
*   Serve as a data source for other features.
*   Makes it easier for business owners to manage responses
