### Wordmark
"Satu" = primary blue `#2563EB`, "Inbox" = near-black `#0F172A`.
Tagline: "One Conversation. More Possibilities."

### Semantic / status (taxonomy color-coding)
- H (high) chip: tint bg + saturated red-ish text
- M (med) chip: amber tint bg + amber text
- L (low) chip: green tint bg + green text
- Priority pills P1/P2/P3: solid fill, white text
- connector-blue `#93C5FD` (dotted 2px dashed), connector-green `#86EFAC`
- gantt bar opacity 0.55

## Shape
- radius pill/badge: 999px
- radius card: ~14px, radius chip: 6px
- number badge: circle 24px
- timeline bar: 4px
- accent bar (row left): 3px
- border: 1px hairline `#E2E8F0` on EVERY card; rows 1px `#EEF2F7`
- shadow: flat `0 1px 2px rgba(15,23,42,.04)`; reserve one soft shadow for hero/center card only

## Typography
- Geometric/humanist sans (Inter/Segoe feel)
- heading weight bold, body regular
- Sentence/Title case ONLY, never uppercase labels
- light letter-spacing on headings

## Layout
- Dense table: row ~27px, cell padding-x 12px
- Airy header/KPI strip: 24px gaps, 20px card padding
- Sidebar ~180px; page padding 24px
- Card-based throughout
- grid lines: horizontal row rules + faint vertical `#EEF2F7` between timeline columns

## Restyle rules for coder
- Every region = white card, `--r-card`, `1px solid var(--border-hairline)`, `--shadow-flat`. Reserve `--shadow-soft` for ONE hero/center card.
- Badges/pills → `--r-pill`, solid semantic fill, white text. Status chips (H/M/L) → `--r-chip`, tint bg + saturated text.
- Sentence/Title case only — NEVER uppercase body/headers.
- Color-code by taxonomy (priority + strategic area).
- Kill existing purple gradient core → use flat navy `--inverse` `#12386E` for the hero SatuInbox block; keep it as the single elevated card.
- Kill dotted `#c3cbdc` connectors → use `--connector-blue` dashed 2px.
