# Monthly Deck Template

Report Type: Monthly Product Progress

## Required Header
- Project name
- Meeting date / reporting period
- Deck generated date
- Last released version
- Ongoing version
- Next planned version

## Slides
1. Title
2. Executive Summary
3. Progress (Last 2 Months)
4. Version Timeline
5. Feature Progress
6. Current Sprint / Current Version
7. Timeline / Gantt / release view
8. Problem / Blocking
9. Difficulty Analysis / workload proxy
10. Upcoming Release
11. Q&A

## Content Rules
- Show actual progress, not only plan.
- Use actual dates when available.
- If date missing, label `Estimated` or `Belum tersedia`.
- Keep points short and management-friendly.
- Highlight blocker and risk early.
- Explain complexity through status/type mix if explicit difficulty field does not exist.
