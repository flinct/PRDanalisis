# Weekly Deck Template

Report Type: Weekly Product Progress

## Required Header
- Project name
- Meeting date
- Deck generated date
- Closed version
- Ongoing version
- Next planned version (optional if relevant)

## Slides
1. Title
2. Executive Summary
3. Version Progress
4. Current Feature Status
5. Problem / Blocking
6. Next Week Plan
7. Q&A

## Content Rules
- Show actual progress, not only plan.
- Use actual dates when available.
- If date missing, label `Estimated` or `Belum tersedia`.
- Keep points short and management-friendly.
- Highlight blocker and risk early.
- Mention current version focus clearly.
