# Release Notes

**Version:** 2.8.0
**Date:** 08-08-2026
**Server Environment:** production
**Release Tag:** prod-2.8.0

---

## Highlights

This release delivers several long-awaited features: **Related Conversations Grouping** clusters related discussions in the omnichannel inbox, and **Related Tickets with Merge Suggestions** helps agents identify and consolidate duplicate tickets. The **Global Search** system receives major upgrades — **fuzzy/typo-tolerant matching**, **performance fixes** reducing P95 from 60s to acceptable latency, and a complete **Relation Label management** system including the previously missing **Unlink (Hapus Relasi)** capability. Instagram channels can now be **reconnected instead of re-created** when expired, and WhatsApp integration adds a **number validation API**. Operations improvements include **auto-assign of orphaned conversations to teams** and **server cost optimization** by consolidating instances.

---

## New Features

* **[#1632] Omnichannel Inbox / Related Conversations Grouping**
Related conversations are now grouped together in the omnichannel inbox, providing agents with better context about ongoing customer interactions across channels.

* **[#1633] Ticketing / Related Tickets and Ticket Merge Suggestion**
The system now suggests related tickets and offers merge functionality, reducing duplicate work when customers create multiple tickets for the same issue.

* **[#2360] Instagram — Reconnect Expired Channel Instead of Delete + Re-create**
Expired Instagram channels can now be reconnected in place instead of requiring deletion and full re-setup. Scope: apps/instagram, apps/channel-service (backend) plus Instagram add-on settings UI (frontend).

* **[#2711] Improvement Round Robin**
Enhanced round-robin assignment with batch delivery rules to prevent bottlenecks. Builds on the v2.7.0.2 round-robin improvements with additional distribution logic.

* **[#2836] Hapus Relasi (Unlink Relation Label)**
New feature to unlink relation labels — previously not implemented anywhere in the codebase. Supports both single and bulk unlink operations with a confirmation modal and new API routes.

* **[#2903] Auto-Assign Unassigned Conversations When Channel Added to Team**
When a channel is added to a team, any orphaned open conversations for that channel are now automatically assigned to the team. Eliminates the need for manual conversation sync after channel team assignment.

* **[#2739] Integrate SatuInbox Contact with Lincah Contact via Open API**
Bidirectional contact sync between SatuInbox and Lincah via Lincah's open API.

* **[#2953] Open API — Baileys — Validate Number**
New open API endpoint to validate WhatsApp numbers via Baileys, used for the Salfok integration.

* **[#2969] Global Search — Fuzzy/Typo-Tolerant Matching**
Added fuzzy matching to global search to match the typo-tolerant behavior of the inbox conversation list search. Users no longer need exact spelling to find results.

* **[#2228] Global Search — Improvement Autotag After Search**
Global search results are now clickable/selectable with bulk relation-label tagging per domain (Conversation or Ticket).

* **[#3140] Add Widget chatbox.id for Lincah Company**
Added a dedicated chatbox.id live chat widget for the Lincah company.

## Bug Fixes

### Global Search

* **[#2410] Global Search — Performance Improvement**
Fixed catastrophic latency and failure under concurrent load. Before fix: P95 latency of 60 seconds with 97% failure rate. Root cause addressed: search query optimization and candidate caching.

* **[#2732] Global Search — Atlas $search Fails on Large Tenants (>1000 conversations/tickets)**
Fixed `maxClauseCount` overflow when Lucene's clause limit was exceeded by large candidate-id lists. Solution: chunk candidate-id lists to stay under Lucene's limit.

* **[#2607] Global Search — Error Opening Related Conversation**
Fixed two issues: (1) clicking a row accidentally triggered checkbox selection instead of navigation, (2) "Hapus Relasi" unlink button was missing from the UI.

* **[#2622] Global Search — Cross-Domain Selection Not Disabled**
Fixed a bug that allowed selecting both Conversation and Ticket domain results simultaneously in global search, which caused undefined behavior.

* **[#2905] Global Search — Ticket Relation Label Badges Not Appearing**
Fixed ticket relation label badges not rendering in global search results despite being saved in the database.

* **[#2906] Global Search — Relation Label No Character Limit + UI Error**
Added 50-character limit for relation label names and fixed modal/UI overflow breakage for long names on detail pages.

* **[#2915] Global Search — Label Not Synced to Current Relation List**
Fixed stale relation label badges persisting in global search results after the label was deleted. Required a hard refresh to clear before the fix.

* **[#2660] Global Search — Tag Relasi Edited Value Not Synced to Modal**
Fixed edited "Tag Relasi" input value not carrying over to the "Beri Tag Relasi" modal's value field.

* **[#2665] Global Search — UI/UX Polish Collection**
Collection of minor fixes: cursor/hover behavior, toast message clarity for relation label operations.

* **[#2981] Global Search — Bug UI on Modal "Lepas Label Relasi"**
Fixed the unlink-relation modal breaking/overflowing horizontally for long relation label names.

* **[#2982] Global Search — Can't Delete Relation Label with 40+ Characters**
Fixed relation-label release/unlink action erroring out for labels with 40 or more characters.

### Conversations

* **[#2916] Unable to Copy/Paste in Ticket Creation Modal**
Fixed copy and paste not working inside the ticket creation modal in the conversation view.

* **[#3104] Inbox — Chat List Preview Not Truncated**
Fixed message preview text in the conversation list not truncating with ellipsis. Missing CSS `overflow` property caused the text to be scrollable instead of truncated.

### Broadcast

* **[#2958] WhatsApp API Templates Created in Meta Business Manager Never Sync to DB**
Fixed Meta-created WhatsApp templates failing to sync to local database due to a bogus required-token validation that rejected valid templates.

### Widget

* **[#2700] Widget Anomaly Socket Event — Flaky**
Fixed widget messages being intermittently skipped or dropped after server restart or release deployment. Socket event handling was not properly re-established after reconnection.

## Rollback Plan

- Global Search performance changes are backend-only; rollback is safe but search latency will revert.

- Auto-assign on channel add (#2903) is event-driven — rollback stops auto-assignment, no state corruption.
