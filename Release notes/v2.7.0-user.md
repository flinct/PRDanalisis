# Apa yang Baru di SatuInbox v2.7.0

_(termasuk hotfix v2.7.0.2 dan v2.7.0.3)_

## ✨ Fitur Baru

- **Global Search** — Cari conversation dan ticket sekaligus dari satu kolom pencarian, lintas domain.
- **WhatsApp: Contact, Poll & Event** — Dukungan tipe pesan baru: kartu kontak, polling, dan event dari WhatsApp.
- **Reply dari Bubble di Ticket** — Balas pesan langsung dari bubble yang dipilih di ticket room, gak perlu scroll ke bawah.
- **Open API Team Inbox** — Akses data team inbox dari API eksternal.
- **Copy-Paste di Chatbox Widget** — Sekarang bisa copy-paste langsung dari clipboard di widget live chat.
- **Baileys v7 Upgrade** — Engine WhatsApp Web di-upgrade ke versi terbaru, lebih stabil.
- **Spintext Dinamis** — Konfigurasi spintext bisa diubah langsung dari settings, gak perlu deploy ulang.

### v2.7.0.2 — Optimisasi Performa

- **Landing Page Setelah Login** — Setelah login, user masuk halaman loading sebelum ke workspace — memberi waktu sistem menyiapkan data.
- **Workspace Lebih Ringan** — Semua accordion di sidebar collapsed by default, data baru di-fetch saat dibuka. Jauh lebih cepat.
- **Round Robin Diperbaiki** — Pembagian percakapan ke agent sekarang batch (5 per member), lebih merata.
- **SLA Tanpa Cron** — Perhitungan SLA pakai event-driven, bukan cron — mengurangi beban database.
- **Sync WhatsApp Lebih Terkontrol** — Setelah scan, user bisa pilih rentang sync (1 minggu/2 minggu/1 bulan). Queue sync dipisah dari inbound.
- **Analytics Cukup Sekali Sehari** — Pre-compute analytics jalan satu kali per hari (tengah malam), bukan terus-menerus.

## 🐞 Perbaikan Bug

- Export/filter di halaman Invoice sekarang berfungsi normal.
- Conversation yang sudah disconnect/delete gak bisa lagi di-reopen.
- Broadcast gak terkirim kalau saldo Rp 0.
- Jam notifikasi sekarang tampil waktu lokal, bukan UTC.
- Badge "Late" dan "Reschedule" di visit history lebih rapi.
- File HEIC dan HEIF sekarang bisa diupload.
- Perubahan shift hour sekarang berdampak ke anggota.
- Status WhatsApp Web account channel sekarang konsisten.
- Pesan WhatsApp Group dari participant tertentu sekarang muncul + reply context tersedia.
- Ticket → conversation link sekarang dynamic (bukan URL statis).
- Conversation gak lagi terbuat kosong dari WhatsApp API.
- Validasi nomor telepon dan email di form lead diperbaiki.

### v2.7.0.2 — Bug Fixes

- **Pesan ganda** — Pesan yang kadang terkirim dobel sudah diperbaiki.
- **Blank screen** — Layar putih/kosong setelah login karena connection pool habis — pool dinaikkan ke 50 + tambah indexing DB.
- **Crash di group message** — WhatsApp group message bikin service crash (maximum call stack); root cause: circular reference di Mongoose subdocument. Di-fix dengan extract field tertentu saja + recursion guard.

### v2.7.0.3 — Hotfix

- **RabbitMQ export macet** — Export job terhenti karena consumer ack error. Ditambah auto-heal monitoring untuk mencegah terulang.
- **Judul room conversation** — Bug di tampilan judul room diperbaiki.
- **Export offline 0 data** — Export offline sekarang menghasilkan data yang benar (payload pakai memberId, bukan userId).
- **Subject email kepanjangan** — Subject email conversation >100 karakter sekarang terpotong rapi dengan tooltip.
