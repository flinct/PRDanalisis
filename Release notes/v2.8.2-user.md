# Apa yang Baru di SatuInbox v2.8.2

## ✨ Fitur Baru

- **Mention peserta di WhatsApp Group** — Sekarang bisa mention peserta grup pakai "@" langsung dari SatuInbox: cari peserta by nama/nomor, mention banyak orang sekaligus, plus badge "Internal" untuk peserta internal.
- **Dashboard Statistik interaktif (drill-down)** — Kartu statistik di halaman Agent Dashboard sekarang bisa diklik untuk lihat detail, navigasi otomatis dengan filter, dan hasil tampil di modal.
- **Kolom "dibuat pada" di template broadcast** — Daftar template broadcast sekarang menampilkan kolom tanggal dibuat (created at), bukan cuma tanggal update.
- **Webhook pesan masuk untuk Salfok** — Pesan masuk bisa diteruskan otomatis ke webhook eksternal untuk verifikasi partner (integrasi Salfok).

## 🐞 Perbaikan Bug

- **Metrik agent saat close percakapan (termasuk bulk)** — Sebelumnya menutup percakapan (satu atau sekaligus) tidak mencatat metrik agent dengan benar karena salah acuan (pemakai tombol, bukan agent penangan); sekarang dicatat ke agent yang tepat.
- **SLA TTC dihitung pakai jam kerja agent yang benar** — Sebelumnya kalau supervisor/admin yang menutup percakapan, SLA dihitung pakai jam kerja & timezone mereka, bukan agent penangan — bikin data SLA salah diam-diam. Sudah diperbaiki.
- **Percakapan dengan banyak agent tidak lagi nyangkut sebagai "aktif"** — Saat percakapan dengan 2+ agent ditutup, agent yang tidak dikredit dulu tetap terhitung punya percakapan aktif selamanya; sekarang semua ikut ter-finalize.
- **Kartu KPI Tiket di Analytics muncul lagi** — Sebelumnya kartu KPI tiket error (data source lama sudah mati); sekarang jalan normal.
- **Handle status akun WhatsApp API** — Menangani webhook update/banned/reinstated akun WhatsApp.
- **Stabilitas notification-service** — Perbaikan crash service notifikasi saat antrian reminder timeout.
- **Antrian refresh token Instagram** — Antrian refresh token Instagram yang sempat macet (540 pesan nyangkut) sudah diperbaiki.
- **Deteksi tipe percakapan grup** — Percakapan grup terdeteksi benar (isGroup) + nama grup ikut ter-sync.
